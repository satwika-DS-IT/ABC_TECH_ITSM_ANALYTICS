# Dataset Information

This directory is reserved for the dataset required by the ABC Tech ITSM Analytics project.

## Dataset Overview

- Dataset: ABC Tech ITSM Incident Dataset
- Total Records: 46,606
- Total Columns: 25
- Historical Period: February 2012 – March 2014

## Dataset Availability

The original dataset is not included in this public repository because it contains client-provided information.

Users must obtain the dataset through an authorized source before running the notebook.

## Local Setup

1. Obtain the dataset through an authorized source.
2. Place the CSV file in this directory.
3. Update the dataset path in the Jupyter Notebook if necessary.

## Important

Do not distribute or publish the original dataset without the appropriate authorization.
