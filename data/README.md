# Dataset Information

This folder contains information about the dataset used in the ABC Tech ITSM Analytics project.

- Dataset: ABC Tech ITSM Incident Dataset
- Records: 46,606
- Columns: 25
- Period: February 2012 – March 2014

The original dataset is not included in this repository.

Users must obtain the dataset through an authorized source before running the notebook.

Please do not share or publish the original client dataset without permission.
